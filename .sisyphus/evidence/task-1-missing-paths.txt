## Key finding: Two parallel answer paths in evaluate_single()

`evaluate_single()` at line 651-654 shows:
```python
system_prompt = await build_assembled_system_prompt(memories)  # Path A
memory_context = _format_eval_memory_block(memories, [])         # Path B (duplicate call)
hypothesis = await answer_with_llm(
    question_text, memories, benchmark_mode=benchmark_mode, system_prompt=system_prompt
)
```

Both `build_assembled_system_prompt()` AND `_format_eval_memory_block()` are called with the same `memories` list. This means:
1. `_format_eval_memory_block()` is called TWICE per question (once inside `build_assembled_system_prompt`, once standalone)
2. The standalone call at line 652 is ONLY for `answer_prompt_metadata.memory_content` (captured for checkpointing)
3. The answer model receives `system_prompt` from Path A only
